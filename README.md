# Dashcam Investigation Suite

**Professional Windows software for reviewing, organising and investigating dashcam and video evidence.**

Dashcam Investigation Suite (DI) is a Windows desktop application for reviewing, cataloguing and investigating dashcam, CCTV and other video recordings while preserving the original source material.

> **The video is the evidence.** DI is designed so original evidence sources remain read-only and are not altered by the application.

## What DI does

DI brings the main stages of video review into one application, including:

- catalogue and organise dashcam, CCTV and general video sources;
- review synchronised front and rear recordings from dual-camera dashcams;
- play and review recorded audio alongside video, with audio controls during investigation;
- seek, scrub and move through recordings precisely;
- use zoom, pan and full-screen review tools;
- review GPS position and map context when compatible GPS data is available;
- create incidents and record descriptions and investigator notes;
- manage imported recordings in a structured local library;
- protect selected material from housekeeping operations;
- use recycle-bin and housekeeping tools for managed copies;
- generate investigation reports;
- work with multiple data sources and camera profiles.

## Evidence integrity

DI distinguishes between **original source evidence** and data that DI manages itself.

Original registered evidence sources are treated as read-only. DI does not intentionally rename, move, delete or rewrite files on original dashcam cards, CCTV exports or other external evidence locations. Application-generated indexes, metadata and managed copies are stored separately.

Removing or expiring a DI licence does not delete, hide, encrypt, watermark or modify a customer's original video files.

## Camera and source compatibility

DI is designed around profiles rather than a single camera manufacturer. Current development and verification include 70mai A800-series material, while the application also supports generic video and CCTV/security exports.

Additional camera manufacturers and recording formats will be verified progressively. Where compatibility has not yet been confirmed, users can test their material during the free 30-day trial.

## Windows requirements

DI is a Windows desktop application built for modern 64-bit Windows systems. The public release will be supplied as a Windows installer.

Large video investigations can require substantial local storage, depending on the amount of material imported into the managed library.
